Core Web Vitals Guide

          
This utility uses static code scanning and runtime
            Lighthouse auditing to verify performance, interactivity, and visual stability metrics.

          
• LCP (Largest Contentful Paint):
            Measures loading performance. Target: ≤ 2.5s.

          
• CLS (Cumulative Layout Shift):
            Measures visual stability. Target: ≤ 0.1.

          
• TBT (Total Blocking Time):
            Measures responsiveness. Target: ≤ 200ms.
